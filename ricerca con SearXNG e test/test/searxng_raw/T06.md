- `readHeadings=true` → heading semantici puliti ("Differences between types and interfaces", "When to use types vs. interfaces", "Declaration merging", ...).
- `section:"When to use types vs. interfaces"` → **estratto**: interface per declaration merging / estendere librerie / stile OOP con `extends` (più performante); type per conditional/generic/union/tuple.

**Risposta**: usa `interface` quando serve declaration merging, contratti di classe, estensione di librerie (extends più
performante e leggibile); usa `type` per union, intersezioni, tuple, conditional/generic types, alias di primitivi.
Default moderno: type, interface per merging/contratti classe. Fonti EN.
