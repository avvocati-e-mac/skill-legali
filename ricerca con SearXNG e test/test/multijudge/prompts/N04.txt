## Concetti base: async/await

In Python, `async` definisce una coroutine, mentre `await` sospende l’esecuzione finché l’operazione asincrona non termina.  Il modello standard ruota attorno a event loop, coroutine e task della libreria `asyncio`.[3][4][1]

Esempio minimale (vale sia per 3.10 che per 3.12):

```python
import asyncio

async def io_bound_task(name, delay):
    print(f"Start {name}")
    await asyncio.sleep(delay)  # simula I/O
    print(f"End {name}")
    return name

async def main():
    # esegue le coroutine in parallelo (concorrenza I/O-bound)
    results = await asyncio.gather(
        io_bound_task("A", 1),
        io_bound_task("B", 2),
        io_bound_task("C", 1),
    )
    print("Results:", results)

if __name__ == "__main__":
    asyncio.run(main())
```
